Twigo Daily Reset Fix and Event Ticket Compensation

Published: July 28, 2026 · Patch completed: July 28 05:32 UTC · Compensation update: July 29 09:33 UTC

Direct answer: Netmarble completed the July 28 server patch at 05:32 UTC, fixing intermittent daily-reset failures in Confirmed! Twigo. On July 29 at 09:00 UTC, affected players received 10 Confirmed! Twigo Event Tickets for each impacted day.

Patch schedule

The official window ran from 05:00 to 05:32 UTC on July 28. It was a server patch without maintenance, so the game remained available while the update was applied.

What did the patch fix?

The only listed fix is the intermittent Confirmed Twigo daily-reset failure. The Version 1.7 known-issues notice now lists that item as resolved on July 28.

Who received compensation?

Players whose reward rearrange count did not reset during the event period received Confirmed! Twigo Event Tickets on July 29 at 09:00 UTC. Netmarble calculated the distribution at 10 tickets per affected day. This compensation detail was added to the official notice at 09:33 UTC.

What should players do?

Completely close the game and reconnect. Netmarble says the patch is applied sequentially, so the exact timing can vary with connection status. If the event still does not reset after reconnecting, document the reset date and compare the symptom with the latest known-issues notice.
