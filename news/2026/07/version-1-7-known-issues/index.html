Version 1.7 Known Issues Updated July 28: Twigo Reset Fixed

Published: July 15, 2026 · Updated: July 28, 2026 05:35 UTC · Official source: Version 1.7 Known Issues

Direct answer: Netmarble updated the Version 1.7 known-issues notice on July 28 at 05:35 UTC. The intermittent Confirmed! Twigo daily-reset failure is now resolved after the July 28 server patch. The too-long Invincibility window for a certain jump action remains active and is scheduled for the next update.

Active issue added July 27

  • A certain jump action can have a longer Invincibility window than intended against Boss Challenge 「Corrupted」 Ancient Dragon, the Book of Stars Dungeon, Demon Hendrickson in Timespace Junction Sector 8, and Shakeera in Deep Spider Nest. Netmarble says this is scheduled for the next update.

Other active Version 1.7 issues

  • Switching to a different weapon type than the one registered for Knighthood Combat Class can incorrectly change the weapon type and Combat Class displayed on the Leaderboard.
  • The weapon type button may not appear in the upper right corner when selecting Quick Equip for an Accessory in the Bag.
  • The Top % text for your record may not appear in Leaderboard Previous Season Ranking Info.
  • Steam error 30021225-0 can block access. Official fix: update the Steam build to the latest version.
  • Leaving a party at a specific location may move the character to a specific area. Official temporary fix: reconnect to the game.
  • Characters may occasionally fall endlessly beneath the ground. The official notice says this will be addressed in a future update.

Resolved on July 28

  • The Confirmed Twigo event could intermittently fail to perform its daily reset. The July 28 server patch fixed the issue; fully exit and reconnect to apply the patch.

Resolved on July 24

  • Certain wording in the Potential effect descriptions for some heroes could be misleading. Netmarble says the wording has been updated for clarity and does not affect the actual Potential effect.

Resolved on July 22

  • Clear records of 1.8 seconds or less for Boss Challenge 「Corrupted」 Barbarian Chieftain Durak [Abyss] difficulty not reflecting properly on the Leaderboard.
  • Armor Set piece counts for the currently selected weapon type not displaying correctly.
  • NPC Slater not appearing when moving to Liones Castle after clearing Main Quest Act 15.
  • Raid Missions - Conqueror's Path event period displaying as Always Available on the mission screen.

What should players do now?

Fully exit and reconnect before checking the Twigo reset again. If Steam access fails with 30021225-0, update the Steam build before deeper troubleshooting. If party movement issues happen, reconnect first because that remains the official temporary path.
