Europe Server Connection Instability Resolved July 16

Published: July 15, 2026 · Updated: July 16, 2026 · Official status notice

Direct answer: Netmarble says the Europe server connection instability was resolved as of July 16, 2026 at 00:38 UTC. The game should now be available for normal play. If connection errors continue on your account, restart the client, check for the latest build, then compare your issue with the current known-issues page.

What changed?

The July 15 notice first acknowledged connection instability affecting official server access, then updated the status to resolved after the issue was addressed. This page is a short status record, not a new maintenance window or compensation notice.

What should players do now?

  • Try reconnecting after fully closing the game client.
  • Confirm your game build is current, especially if you play on Steam.
  • If the problem is no longer a broad server outage, check whether your symptom matches the active Version 1.7 known issues.
