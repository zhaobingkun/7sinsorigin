September 7 Server Patch Completed

Published: September 7, 2026 · Patch completed: September 7, 2026 06:08 UTC

Direct answer: The official September 7 server patch is completed. It fixes an issue that could intermittently prevent players from starting the Holy Knights and Thieves minigame under certain conditions.

What did the patch fix?

Netmarble lists one confirmed fix: players could intermittently be unable to play the Holy Knights and Thieves minigame under certain conditions. The patch is a targeted stability and event-access correction; it does not announce a new banner, event schedule, reward, rate, or Labyrinth release.

What should players do?

Reconnect to the game after the patch is applied. The official notice warns that temporary connection instability may occur during the sequential rollout, and timing can vary with connection status.

Does this change the current event pages?

The patch supports the existing Holy Knights and Thieves event coverage but does not change its rules or rewards. Use the event guide for the current minigame context, and check the Version 2.0 Known Issues page if a separate problem remains.
