Version 2.1 Known Issues Updated October 8

Published: September 17, 2026 · Updated: October 8, 2026 10:00 UTC

Direct answer: The official Version 2.1 notice was updated on October 8. The remaining listed issues are incorrect Hawk Pass XP, Steam error 30021225-0, party-leave movement, and characters falling beneath the ground. Khala’s Copycat and Mirror Arsenal issues, Hero Tag overlap, Skip input, and the controller Set Effect cursor issue are marked resolved.

Remaining Version 2.1 issues

  • Hawk Pass Mission rewards may apply the wrong amount of Hawk Pass XP.
  • Steam error 30021225-0 may block access; updating the Steam build to the latest version is the official workaround.
  • Leaving a party at a specific location may move the character elsewhere; reconnecting can temporarily resolve it.
  • Characters may occasionally fall endlessly beneath the ground; the official notice says this will be addressed in a future update.

Resolved on October 8

The official notice marks Khala’s Dual Swords Copycat and Mirror Arsenal trigger issues, Hero Tag nickname overlap, the Skip the Main Quest input problem, and the controller cursor disappearing after viewing an Engraved Equipment Set Effect as resolved. Earlier fixes for Indura Monspeet drops, Vanya, Timespace, Hero Pick Up, Windflower, and PlayStation 5 issues remain recorded as resolved.

What should you do?

Fully exit, install the latest platform or Steam update, reconnect, and retry. For the current Version 2.2 issue list, use the newer official notice; do not treat a remaining Version 2.1 issue as resolved unless Netmarble marks it resolved.
