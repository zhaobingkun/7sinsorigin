Rewinding Fate：Memory of Dimensions

发布时间：2026-08-12 · 官方活动公告

直接答案：官方 Memory of Dimensions 允许玩家通过单人剧情任务重温《七大罪》原作中的关键事件。内容在 8 月 12 日维护后开放，需要完成主线 Holy Knight Marmas，并可获得 Star Fragment 等奖励。

Memory of Dimensions 怎么进入？

打开 Menu（☰）→ Book of Stars → Memory of Dimensions，选择已解锁的任务并点击 Start。首个新增任务是 The Rusted Armor Knight's Identity。

任务有哪些规则？

  • 内容仅限单人，组队状态下不能游玩。
  • 同一时间只能进行一个任务。
  • 中途离开不会清空进度，可通过 Continue 继续。
  • 官方将按顺序继续追加 Memory of Dimensions 任务。

活动什么时候结束？

官方公告写明活动从 8 月 12 日维护后开始，持续到另行通知（UTC）；目前没有固定结束日期。

官方来源：Rewinding Fate - Into the Memory of Dimensions。
