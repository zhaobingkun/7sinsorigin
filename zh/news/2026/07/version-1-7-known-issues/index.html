1.7 已知问题 7 月 22 日更新：Knighthood 排行与已解决修复

发布时间：2026-07-15 · 更新：2026-07-22 08:15 UTC · 官方来源：Version 1.7 Known Issues

直接答案：Netmarble 的 1.7 已知问题公告已在 7 月 22 日 08:15 UTC 更新。Durak Abyss 排行榜记录、Armor Set 件数显示、Act 15 后 Slater 不显示、Raid Missions 时间显示这 4 项已标记为解决；新列出的当前问题是 Knighthood Combat Class 相关的武器类型和 Combat Class 排行显示异常。

1.7 当前已知问题

  • 切换到与 Knighthood Combat Class 登记不同的武器类型时，Leaderboard 上显示的武器类型和 Combat Class 可能被错误改变。
  • 在 Bag 里给 Accessory 使用 Quick Equip 时，右上角可能不显示武器类型按钮。
  • Leaderboard 的 Previous Season Ranking Info 中，个人记录的 Top % 文本可能不显示。
  • Steam 错误码 30021225-0 可能导致无法进入游戏。官方处理方式：将 Steam build 更新到最新版本。
  • 在特定位置离队后，角色可能被移动到特定区域。官方临时处理方式：重新连接游戏。
  • 角色可能偶尔无限掉到地底。官方公告称会在后续更新中处理。

7 月 22 日已解决

  • Boss Challenge 「Corrupted」 Barbarian Chieftain Durak [Abyss] 难度中，1.8 秒或更短 clear record 没有正确反映到 Leaderboard。
  • 当前选择武器类型下，已装备 Armor Set 件数显示不正确。
  • 完成 Main Quest Act 15 后前往 Liones Castle，NPC Slater 不显示。
  • Raid Missions - Conqueror's Path 的 mission 画面把活动期间显示为 Always Available。

现在怎么处理

Steam 出现 30021225-0 时，先更新 Steam build。离队后位置异常或角色状态异常时，仍优先重新连接游戏，再继续排查。
