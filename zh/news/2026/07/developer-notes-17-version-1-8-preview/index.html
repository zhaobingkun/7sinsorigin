Developer Notes #17：1.8、Hunting Event 与半年庆路线

发布时间：2026-07-30 · 官方更新时间：2026-07-31 08:45 UTC

直接答案：Developer Notes #17 把 1.8 定位为半年庆 2.0 的前置版本。重点包括限时 15 人 Hunting Event、首章 Memory of Dimensions 原作剧情任务、信息显示与重试 QoL、早期成长任务改版、Timespace Junction 第一季终章，以及支援奖励。

15 人 Hunting Event 怎么玩？

最多 15 名玩家会在同一战场共同挑战一个 Boss。最多 5 人的队伍可以一起匹配。这是限时活动，不是常驻内容，但官方计划以后定期复刻。

Memory of Dimensions 是什么？

Memory of Dimensions 是在游戏内重现动画经典事件的 Original Story Quest。第一章围绕 Meliodas 与 Elizabeth 的羁绊展开，未来章节会继续回顾七大罪成员共同经历的旅程。

1.8 QoL 改进

  • 游戏内直接显示 Set Item 附加信息。
  • Codex 与 Special Codex 条目显示获取来源。
  • 此前隐藏的 Point Fishing Spot 会显示在地图上。
  • Dungeon、Boss Challenge 与 Raid 通关后可不离开场地直接重试。
  • Boss Challenge 在战斗仍进行时也可以重新开始。

任务改版与免费抽卡券

Path of the Hero 和 Challenge Missions I-III 会提高早期成长奖励。接下来 5 周，每周一 09:00 UTC 发放 Regular Hero Draw Ticket x10，总计 50 张；每封邮箱奖励需要在 7 天内领取。

1.8 感谢奖励

  • Radiant Potion of Charm x3
  • Remnants of the Rift x3
  • Tailor's Stitching Needle x5
  • Element Spell Bead Selection Chest x3

官方说明奖励会在 1.8 更新后开放领取，截止到 8 月 26 日 14:59 UTC。

Timespace 与前期体验变化

Timespace Junction 第一季会以 Sector 12 结束，并在半年庆重置前保留两周。第二季随 2.0 开启，所有 Sector 重置并从 Sector 1 重新开始。1.8 还会加入早期洞窟教程跳过、提高 World Level 3 奖励，并调整多目标战斗中的 Tag Skill 触发规则。

哪些信息还没确认？

Developer Notes #17 没有公布下个 Hero Pick Up、卡池日期、概率或保底变化。1.8 路线属于已确认内容，但不能当成卡池官宣。
