7DS Origin Codes: Verification and Reward Checks

A code is not “working” without a verifiable source. This page explains our list status and a safe verification procedure.

Editorial review: October 11, 2026. Official facts and our analysis are identified separately.

Verified-code list on this site

This tracker currently has no verified code to list. That describes our evidence, not a claim that no active code exists in every region or official channel. We will not fill a code table with guesses.

Check-In, Bingo and hero trials have their own entry and claim requirements. An in-game reward mail labeled Coupon Reward is not by itself proof of a public redeem code.

Check a code someone shared

  1. Find the original official notice or official-account post, not another site's “working codes” table.
  2. Record case, expiry, region/platform requirements and reward. Do not invent conditions missing from the source.
  3. Redeem only in-game or through the official entry point. Do not provide passwords or payment information or install a reward-claim tool.
  4. Record the exact used, expired or ineligible message. One account's failure does not establish that the code fails for everyone.

A code belongs here only once its source and conditions can be checked. Unsupported success-rate claims and unattributed claim screenshots are not verification.

Current rewards that do not require a code

The event deadline and claim checklist covers Check-In, Bingo and Cube. The resource ledger distinguishes reward limits and ticket types. Start source verification at the official news entry.
