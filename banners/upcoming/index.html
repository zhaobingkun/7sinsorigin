Upcoming Banners

Use this page for planning, not certainty. Upcoming banner pages should stay close to official reveals, patch notes, and character pages so players can decide whether saving now makes more sense than pulling immediately.

No Next Banner Confirmed

Netmarble has not announced the Hero Pick Up banner that will follow Gowther as of July 31. Gowther is the current Version 1.7 pickup and is scheduled to remain available until the August 5 maintenance. Treat character names circulating without an official notice as speculation.

Current Banner Status · Gowther Pick Up Details

What Is Confirmed Now

  • Gowther Pick Up runs until the August 5 maintenance.
  • The banner uses Hero Pick Up Draw Tickets.
  • It guarantees at least one SSR within 80 draws.
  • If an SSR is not the pickup hero, the next SSR is guaranteed to be the pickup hero.
  • The 120th Draw Bonus guarantees the pickup hero once on this banner and does not carry to another Hero Pick Up event.

Save or Pull Logic

Pull only if Gowther fills a real support, raid, or team-building need for your account. If he does not, keeping tickets for the next official reveal is safer than spending based on an unconfirmed successor.

Version 1.8 Is Not a Banner Reveal

Developer Notes #17 confirms Version 1.8 content and rewards but does not name the next pickup, banner dates, rates, or pity changes. This page will change only after an official notice identifies the successor.
